# Zomato Profitability Analysis — FY22 to FY24

## Project Overview
A complete data-driven strategy analysis of Zomato's 
profitability journey from FY22 to FY24, covering food 
delivery turnaround, Blinkit unit economics, and the 
self-funding cross-subsidy structure.

## Central Business Question
Is Zomato's Blinkit bet a justified long-term growth play, 
or is it delaying overall profitability?

## Key Findings
- Food delivery EBITDA flipped from -₹766 Cr to +₹912 Cr
- Blinkit loss per order reduced 78%: -₹85 to -₹19
- Food delivery funds Blinkit with ₹528 Cr surplus in FY24
- Cash reserves grew from ₹7,782 Cr to ₹12,241 Cr

## Tools Used
- MySQL — data modelling and analysis
- Python (Pandas, Matplotlib) — EDA and visualisation
- Power BI — interactive dashboard

## Data Source
Zomato Annual Reports FY2022, FY2023, FY2024
(publicly available at investors.zomato.com)
